# Docs — Skills

Navigation note. Canonical sources: [`docs/skills-guide.md`](../docs/skills-guide.md) (how to use,
create, and manage skills) and [`docs/SKILLS.md`](../docs/SKILLS.md) (the skill catalog).

Skills are slash commands that teach Claude *when* and *how* to apply specialized reasoning. Only
~70 tokens of metadata per skill load at startup; full content loads on invocation. The bundled
catalog the scaffolder installs lives in the repo's top-level `skills/` dir.
